RFP (the call) Donor profile Org (you) component: 1 / 0.5 / 0 criterion: 2 / 1 / 0 · Not sure → 1 (Park)
ACTIVE-ONLY scoring (2026-06-29). A component is scored ONLY when the call/donor imposes it, or a proxy applies (e.g. registration via the call's geo-scope). An undetected component is "Not sure" — excluded from that criterion's denominator, never a permissive pass. A criterion with NO active component resolves to "Not sure" → value 1 (Park): an unknown routes to manual review, it never auto-passes and never auto-Declines. A clearly DETECTED failure still scores 0 and gates. Exception: SAM.gov/UEI only applies to US-federal (grants.gov) calls, so for every other donor it is a permissive pass (value 1, "no restriction") rather than "Not sure".
Bid Strength = the 9 weighted criteria (100%). The funder's requirements and the call's requirements are matched against the org INSIDE the 9 criteria (each criterion blends RFP + Donor sources — see the source tags below). There is no separate "funder-fit" add-on: the old 20% extras duplicated MUST-2 / MUST-4 / MUST-5-route / PREFER-7, so they were dropped (2026-06-29) to avoid double-counting.
